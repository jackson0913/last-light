# Last Light

A tiny browser-based action game prototype built for the `jackson0913/last-light` repository.

## Play locally

Open `index.html` in a browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- Move: `WASD` or arrow keys
- Attack: `Space`
- Dash: `Shift`
- Pause: `P`

## Goal

Defeat incoming enemies, collect loot, and survive as long as possible while exploring the ruins of Last Light.
